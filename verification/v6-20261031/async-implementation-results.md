## Limits and handoff

No automatic retry occurs, including429 and unknown write outcomes. Retry-After is exposed to callers as bounded seconds, not a mutation retry schedule. Client timeouts bound waiting; they cannot establish whether an interrupted server write committed. Server transaction/idempotency/concurrency checks remain required and are verified by the other agents' isolated HTTP/database suites.

All current scenario editor/lifecycle PATCH requests include expected_revision from the API record that the user loaded. Missing revision blocks the UI write. A409 preserves the builder and explains copying changes/reloading current state; no background refresh replaces input. Scenario creation remains an explicit POST without an existing revision.

No CSS, approved palette, spacing, logo, shared layout markup or navigation links were changed here. Layer-token inconsistencies and the seven requested responsive widths remain with the root agent for measured browser verification. No arbitrary student execution or inference provider was enabled. Documentation, final full-suite runs and release packaging remain root-owned.
